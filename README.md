# local-aur-meta

This repository contains a split meta-package for my personal use.

Each split package takes an AUR package that I install, as well as all of its make and check dependencies, as dependencies.

This is for easier management on my part.
I do not expect anyone to find it useful.
However, if you do, feel free to use this as a reference.
